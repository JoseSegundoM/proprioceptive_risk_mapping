# Contributing

1. **Say what was run.** State whether a change was exercised in tests, in the Monte Carlo or in MuJoCo.
2. **No hand-typed results.** Numbers in the paper come from `paper/tables/values.tex`, generated by `scripts/make_tables.py`.
3. **Keep every run.** Negative results and failed runs stay in `results/`; raw records are never edited.
4. **Evaluation maps tune nothing.** Parameters are tuned on the development maps only (`docs/protocol.md`).
5. **Name the evidence.** Simulation is reported as simulation, and nothing here is described as measured on the robot until it is.

Before opening a pull request:

```bash
python -m pytest tests -q
python scripts/analyze_mc.py && python scripts/make_tables.py
git diff --exit-code results/tables paper/tables
```
